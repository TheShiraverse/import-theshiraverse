Part 1 · What it is

Python is a language for giving instructions to a computer

You write short, readable lines. Python runs them. That is the whole idea.

General-purpose

One language for analysis, automation, websites, science and AI. You are not locked into one job.

Readable

Code looks close to plain English. print('Hello') does what it says.

Huge library of add-ons

Other people's tools for tables (pandas), charts (matplotlib), databases, web data and machine learning. Free.

Pro tip. This runs for real in your browser. Press Run, then change a word and run again.
Part 2 · History

From a Christmas project to the world's everyday language

Facts below are from the official Python FAQ and python.org.

Dec 1989
Guido van Rossum starts writing Python during the Christmas holidays.
Feb 1991
After just over a year of work, Guido posts the first public release to USENET.
2000
Python 2.0 is released.
Dec 2008
Python 3.0 arrives: a cleaner language that is not fully compatible with Python 2.
1 Jan 2020
Python 2 is officially retired: no more fixes, ever.
Oct 2026
Python 3.15 is the latest release (3.15.2 on 25 Oct 2026).
Pro tip. The name is not the snake. Guido was reading scripts from Monty Python's Flying Circus, a 1970s BBC comedy, and wanted a name that was short, unique and a little mysterious.
Part 2 · History

Who looks after Python today

The Python Software Foundation

An independent non-profit that holds the copyright on Python 2.1 and newer and works to promote and protect the language.

Free and open source

You can use Python for work, study or business at no cost. Anyone can read its source code and propose improvements.

Watch out. Always learn and use Python 3. If a tutorial shows print 'hello' without brackets, it is Python 2 and out of date.

Part 3 · Python, SQL or Excel?

Three tools, three strengths

You will use all three. The skill is knowing which to reach for.

Excel

Fast for small data, quick what-ifs and sharing with people who live in spreadsheets. Hard to repeat and audit at scale.

SQL

Best for asking questions of data that lives in a database: filter, join, group. The work happens where the data is.

Python

Best for cleaning messy files, repeating work every week, statistics, charts and anything the other two cannot do. It can also run SQL.

Pro tip. In this course every Python topic points back to the SQL idea you already know, so you are translating, not starting over.
Part 3 · Python, SQL or Excel?

Which tool would you reach for?

Think first, then click to check.

Total sales by city from a database with 20 lakh rows
SQL. The data lives in the database, and GROUP BY runs right there.
A quick what-if on 30 rows to show your manager
Excel. Small, visual, and your manager can open it.
Clean 50 messy CSV files the same way every Monday
Python. Write the steps once, run them every week.
Join three tables and filter by date
SQL if they are in a database. pandas (Python) if they are files.
Run a statistical test and draw a chart for a report
Python. Libraries for statistics and charts are its home ground.
Call a web service and save the JSON it returns
Python. SQL and Excel cannot do this well.
