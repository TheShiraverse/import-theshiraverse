Part 1 · The journey

What happens when you press Run

Python is a program called the interpreter. It reads your code and does what it says, one step at a time.

1 Writeyour code
→
2 Readthe interpreter checks the syntax
→
3 Translateinto bytecode, a compact set of steps
→
4 Runthe Python virtual machine does each step
→
5 Showoutput or an error
Pro tip. SQL runs inside a database server. Python runs inside the interpreter, on your computer, or right here in your browser.

Part 2 · Three ways

REPL, script or notebook

Same language, three places to use it.

REPL

Type a line, see the answer at once. Great for trying things. Nothing is saved. Start it with python or python3 in a terminal.

Script (.py)

A text file of code that runs top to bottom. Best for repeatable work and automation: python report.py.

Notebook (.ipynb)

Code in cells with notes and charts in between. Best for exploring data and sharing results. Jupyter and VS Code open them.

Part 2 · Three ways

In the REPL, the last value is shown for you

Type an expression and Python prints its value. Our cells do the same for the last line.

Pro tip. In a script this echo does not happen. You must write print(...) to see anything.
Part 2 · Three ways

A script knows it is the main program

Every file has a built-in name. When you run a file directly, that name is __main__.

Watch out. You will use this later (if __name__ == '__main__':) to let a file act as both a script and a module.
Part 3 · Versions and files

A version is a number you should know

Python 3.15 is the latest at the time of writing. Libraries state which Python versions they support.

What a version number means

3.15.2 is major 3, minor 15, patch 2. Minor versions add features each year; patches fix bugs.

Why it matters

Code written for 3.8 usually runs on 3.15, but new syntax from 3.15 will not run on old Pythons. Check with python --version.

Pro tip. The browser here runs Python 3.12, a little behind the latest. That is fine: everything in this course works on 3.12 and newer. Your laptop can have the newest version.
Part 4 · Output and errors

An error is information, not failure

Python tells you what went wrong and where. Read the last line first.

Runtime error: the code ran, then broke
Syntax error: Python cannot even start
Watch out. A syntax error stops the program before anything runs. A runtime error happens while it runs, so earlier lines may already have printed.
