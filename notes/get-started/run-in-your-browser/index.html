Part 1 · How it works

Real Python, running in your browser tab

The interpreter you met in the last part has been compiled so it runs inside the browser. No install, no account, works on a phone too.

First run

The first time you press Run, the browser downloads Python (about 10 MB). You will see a message. After that it is fast.

On your device

The code runs on your computer or phone, in your tab. Nothing you type is sent to a server to be run.

Same language

It is genuine Python 3, so what you learn here is what you will use on your laptop.

Part 2 · Using the cells

Every code box on this site is a live cell

Run it, change it, break it. You cannot hurt anything.

Controls
  • Run or Ctrl/Cmd + Enter runs the cell
  • Click in the box and edit the code
  • Reset restores the original code
  • Copy copies it so you can paste it elsewhere

Part 3 · Limits

Know the edges so nothing surprises you

Works in the browser
  • All core Python: values, text, lists, dictionaries, loops, functions, classes
  • Standard library: math, random, datetime, json, re, csv
  • pandas and NumPy (in the playground)
  • Files, held in the browser's memory while the tab is open
Needs your laptop
  • input(): browser cells cannot wait for typing
  • Files that survive after you close the tab
  • Installing extra packages with pip
  • Heavy libraries such as deep-learning toolkits
  • Some web requests, which browsers block for safety
