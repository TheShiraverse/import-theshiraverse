Step 1

Install Python (Windows and Mac)

Get it from python.org/downloads. Python 3.15 is the latest at the time of writing; any recent 3.x works for this course.

Windows
  • Download the Python install manager from python.org/downloads, or get it from the Microsoft Store.
  • Install it, then open a new terminal (PowerShell).
  • The commands python, py and pymanager should now exist.
Check (PowerShell)
py -3 --version
py list
Mac
  • Download Python for macOS (.pkg) from python.org/downloads and open it.
  • Then open the folder /Applications/Python 3.15/ and double-click Install Certificates.command.
  • Do not use or modify the older Python that Apple ships.
Check (Terminal)
python3 --version
Pro tip. You should see a version starting with 3. If you see 2.x, or the command is not found, jump to the problems table later in this page.
Step 1 (alternative)

Anaconda or Miniconda

A bundle that installs Python and manages environments for you. Choose it or plain Python, not both.

Use it if
  • You want one installer that includes data tools
  • Your team or college already uses conda
Create an environment
Terminal (Anaconda Prompt on Windows)
conda create --name ds_env python
conda activate ds_env
conda install pandas matplotlib jupyterlab
Watch out. Do not mix pip and conda for the same package in one environment. Pick one way and stay with it.
Step 2

Install VS Code and the Python extension

VS Code is a free editor from Microsoft. Download it from code.visualstudio.com.

Install the extension

Open Extensions, search Python, install the one by ms-python (id ms-python.python). It does not include Python itself, which you installed in step 1.

Pick the interpreter

Open the Command Palette (Ctrl+Shift+P on Windows, Cmd+Shift+P on Mac) and run Python: Select Interpreter.

Open a terminal

Use Terminal → New Terminal inside VS Code so your commands run in your project folder.

Pro tip. Open a new terminal after installing Python so it picks up the changes.
Step 3

A virtual environment keeps this course tidy

An environment is a private folder with its own Python and its own packages. Projects never fight over versions. Make one inside your project folder.

Windows (PowerShell)
Create and activate
py -3 -m venv .venv
.venv\Scripts\Activate.ps1

If PowerShell says scripts are disabled, run this once:

PowerShell, once
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
Mac and Linux
Create and activate
python3 -m venv .venv
source .venv/bin/activate

Leave the environment any time with:

Both systems
deactivate
Pro tip. When it is active, your prompt starts with (.venv). If you do not see it, you are not inside the environment.
Step 4

Install packages with pip

pip downloads packages from the Python Package Index. Always run it as python -m pip so it uses the Python you think it does.

Install what the course needs
With the environment active
python -m pip install pandas matplotlib jupyterlab
Check it worked
Prints a version number
python -c "import pandas; print(pandas.__version__)"
See and share your packages
List, then save
python -m pip list
python -m pip freeze > requirements.txt
Rebuild elsewhere / remove
Install from the list / uninstall
python -m pip install -r requirements.txt
python -m pip uninstall pandas
Step 5

Run a script and open Jupyter

Create a file called hello.py in VS Code with one line, then run it from the terminal.

A script
In your terminal
python hello.py
A notebook

Either run Jupyter in the browser:

Opens a page in your browser
jupyter lab

or in VS Code create a file named hello.ipynb, choose your .venv kernel, and run a cell.

Self-Check

Can you answer these?

Click a card to check yourself.

How do you check which Python version you have?
Mac: python3 --version. Windows: py -3 --version.
Why use a virtual environment?
Each project gets its own Python and packages, so versions never clash.
How do you know the environment is active?
The prompt starts with (.venv).
Why python -m pip instead of just pip?
It guarantees pip belongs to the same Python that will run your code.
How do you save and restore your package list?
pip freeze > requirements.txt, then pip install -r requirements.txt.
Which VS Code extension do you need?
Python by ms-python (ms-python.python).
