Whole-number divide and remainder

// is floor division: it drops the decimals. % (modulo) is what is left over. Together they split things into groups.

Topic 1 · Operators

** is power

** raises to a power. A fractional power is a root. This is how compound interest works.

Pro tip. Python integers never overflow: 2 ** 100 just works.
Topic 2 · Precedence

Who goes first? Brackets decide

Python follows the maths order: brackets, then **, then * / // %, then + -. When unsure, add brackets.

Watch out. -2 ** 2 is -4, not 4. The power happens before the minus sign.
Topic 2 · Shortcuts

+= and friends update a variable in place

x += 5 means x = x + 5. Every operator has one: -= *= /= //= %= **=.

Common mistake

Dividing by zero

Maths says undefined, so Python stops with ZeroDivisionError. It happens on /, // and %.

Broken
Fixed
Watch out. Check the divisor before you divide. An empty day in RetailMart has zero orders, and an average of nothing is not a number.
Common mistake

-7 // 2 is -4, not -3

// rounds down (towards minus infinity), not towards zero. The remainder follows the same rule.

Broken
Fixed
Watch out. Rule: a == (a // b) * b + a % b always holds. If you want to cut towards zero, use int() or math.trunc().
Common mistake

2 ^ 3 is not 8

In PostgreSQL ^ is power. In Python it is XOR (a bitwise operator), and it runs without any error.

Broken
Fixed
Watch out. No error means no warning. If a power result looks small and strange, check you wrote **.
Topic 3 · Built-ins

abs, round, divmod, min, max, sum, pow

Python ships with small helpers for everyday number work. No import needed.

Pro tip. round(x) with no second argument gives an int. round(x, 2) keeps two decimals and stays a float.
Common mistake

round(2.5) is 2

Python uses banker's rounding: a value exactly halfway goes to the nearest even number. It avoids always rounding up, but it surprises everyone.

Broken
Fixed
Watch out. For rounding that matches a printed bill (half up), use Decimal with ROUND_HALF_UP. round(2.675, 2) gives 2.67 because the float is stored a hair below 2.675.
Topic 3 · math

import math for the rest

A module is a toolbox you bring in with import. math comes with Python.

Pro tip. Use math.isclose() to compare floats. Never trust == on decimals that came from arithmetic.
Topic 4 · Exact numbers

Three ways to hold a decimal

A float is fast but tiny errors creep in. Decimal is exact for money. Fraction is exact for ratios.

float

Fast, approximate. Fine for statistics and measurements.

Decimal

Exact decimal digits. Use for rupees and paise.

Fraction

Exact ratios as a / b.

Common mistake

Decimal from a float, or Decimal plus float

Decimal(0.1) copies the float's error. And a Decimal will not mix with a float.

Broken
Fixed
Watch out. Always build a Decimal from text (Decimal('0.1')), and keep every number in the sum a Decimal.

Interview Studio

Five questions interviewers ask about numbers

What is the difference between / and //?
/ is true division and always returns a float (7 / 2 is 3.5). // is floor division and rounds down (7 // 2 is 3, and -7 // 2 is -4).
What does round(2.5) return, and why?
2. Python uses banker's rounding: exact halves go to the nearest even number. round(3.5) is 4.
Why not use float for money?
Floats are binary, so values like 0.1 are slightly off and errors add up. Use Decimal built from text, or keep whole paise as integers.
What does 2 ^ 3 give in Python?
1. ^ is bitwise XOR. Power is **, so 2 ** 3 is 8.
Does Python have an integer overflow?
No. Integers grow as needed, so 2 ** 100 is 1267650600228229401496703205376. Floats do have limits.
