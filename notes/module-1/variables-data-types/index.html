Main story

The price tag that was text

RetailMart product #1 is the Samsung Animi Max, listed at ₹1,25,812.07. A new analyst reads the price from a file and adds ₹100 handling.

The setup

The price comes out of a file looking perfectly normal: 125812.07. She stores it in a variable called price and moves on.

The bug

Adding 100 crashes with a TypeError. So she adds '100' instead. No error. The answer is 125812.07100: wrong, and silent.

The fix

Files hand Python text. The value was a str, not a number. float() converts it, and now the maths is real maths.

Topic 1 · Variables

Syntax, rules and a few good habits

Assign

One = means store, not "equals". The right side is worked out first.

qty = 2 + 3

Name rules
  • letters, digits, underscore
  • cannot start with a digit
  • no spaces; case matters (Price is not price)
Good habits
  • snake_case names
  • say what it holds: unit_price, not x
  • one idea per variable
Common mistake

Typo or wrong case in a name

Python does not guess. A name that was never created, or spelled with another case, raises NameError.

Broken
Fixed
Watch out. Read the last line of the error first: name 'Price' is not defined tells you exactly what Python could not find.

Common mistake

0.1 + 0.2 is not exactly 0.3

Computers store decimals in binary, so some come out a tiny bit off. It even happens with real RetailMart prices.

Fixed

Topic 3 · Converting

int(), float(), str(), bool() change the type

Data from files and websites arrives as text. Convert it before you do maths.

Watch out. bool('False') is True. Any non-empty text is True. Only 0, empty text, None and empty collections are False.
Common mistake

int() on text that is not a plain number

int() only accepts digits. Decimals and Indian-style commas raise ValueError.

Broken
Fixed
Watch out. Clean first (replace), then convert. For '12.5' go through float() first.
Common mistake

Adding text and a number

Python is strict: it will not mix str and int with +.

Broken
Fixed
Watch out. can only concatenate str (not "int") to str means one side is still text. Convert it.

Interview Studio

Five questions interviewers ask on day one

What is the difference between int and float?
int holds whole numbers, float holds decimals. 5 is an int, 5.0 is a float, and they compare equal (5 == 5.0 is True).
Why is 0.1 + 0.2 not exactly 0.3?
Floats are stored in binary and 0.1 has no exact binary form. The result is 0.30000000000000004. Round for display, or use Decimal for exact money.
Is Python statically or dynamically typed?
Dynamically typed (a name can point to any type) and strongly typed ('1' + 1 is an error, it does not guess).
What is None, and how do you test for it?
None is the single 'no value' object, Python's NULL. Test with x is None.
What does bool('False') return?
True. Any non-empty string is truthy, whatever it says.

1 · A variable is a name

2 · Five types

int, float, str, bool, None. Ask type() when unsure.

3 · Files give text

Test with is None. Not zero, not empty text.

NameError, TypeError, ValueError each say what is wrong.
