Main story

Three Gwaliors

A RetailMart city report counts customers per city. It shows Gwalior three times, each with a small count. Nothing is wrong with the data except how the cities were typed.

The problem

People typed gwalior, Gwalior and GWALIOR. To a computer these are three different texts.

The idea

Clean first, count after. strip() removes stray spaces and title() fixes the capitals.

The result

One clean name, so one correct total.

Story → SQL

The text functions you know, as methods

In SQL you wrap a column in a function. In Python you call a method with a dot after the text.

JobPostgreSQLPython
Upper / lowerUPPER(s), LOWER(s)s.upper(), s.lower()
Trim spacesTRIM(s)s.strip()
ReplaceREPLACE(s, 'a', 'b')s.replace('a', 'b')
SplitSPLIT_PART(s, ',', 2) (starts at 1)s.split(',')[1] (starts at 0)
Format a numberTO_CHAR(n, 'FM999,999.00')f'{n:,.2f}'
Pro tip. Methods are written text.method(). They do not change the text: they hand back a new one.
Topic 1 · Clean text

upper, lower, title, capitalize

Case methods fix inconsistent capitals. Always compare after making the case the same.

Topic 1 · Clean text

Remove spaces, swap pieces

strip() trims both ends (also lstrip and rstrip). replace(old, new) swaps every match.

Pro tip. repr() shows hidden spaces and newlines, so use it when text looks right but behaves wrong.
Topic 2 · Cut and glue

split cuts text into a list, join glues it back

split(sep) returns a list of pieces. sep.join(list) puts them together with sep between.

Pro tip. Splitting on ',' is how you read one row of a CSV file. Topic 24 covers the real thing.
Topic 2 · Search

Where is it, and how many times?

find returns a position or -1. index does the same but raises an error when missing. count counts matches.

Pro tip. Test with find(...) != -1 or simply 'an' in s when you only need yes or no.
Topic 3 · Check

startswith, endswith, isdigit, isalpha

These return True or False. They are the building blocks of simple validation.

Watch out. '12.5'.isdigit() is False because of the dot, and '-5'.isdigit() is False because of the minus. For decimals, try float() and catch the error (topic 25).
Topic 3 · Combine

Each method returns text, so call the next one on it

Read a chain from left to right: the result of one step is the input of the next.

Pro tip. If a chain gets too long to read, split it over two lines or two variables. Clear beats clever.
Topic 4 · Formatting

Put values inside text with f'...{value}...'

Put an f before the quote and write any expression inside { }.

Pro tip. {x=} prints the name and the value: a very fast way to debug.
Topic 4 · Formatting

After a colon, say how to show it

{value:format}. The format says width, alignment, decimals and thousands separator.

Watch out. The comma separator is western grouping: 1,258,120. Python has no built-in lakh grouping like 12,58,120, so for lakh style we write a small helper later.
Topic 4 · Formatting

You will see these in older code

Same results, older syntax. Read them, but write f-strings.

Pro tip. %s text, %d whole number, %.2f two decimals. Still common in logging code.
Common mistake

The result was thrown away

Strings cannot change, so a method never edits the original. If you do not save the result, nothing changed.

Broken
Fixed
Watch out. Assign the result back (city = city.strip()). This is the number one string mistake of beginners.
Common mistake

Two spaces make an empty piece

split(' ') cuts at every single space. split() with nothing inside splits on any run of spaces and ignores the ends.

Broken
Fixed
Watch out. To split a sentence into words, use split() with no argument.
Common mistake

ValueError: substring not found

find quietly returns -1. index stops the program when the text is missing.

Broken
Fixed
Watch out. Use find or in when the text may be absent. Remember find gives -1, which is a valid-looking index.
Common mistake

{price} printed as it is

Without the f prefix the braces are just text. Also keep the quotes inside the braces different from the outer ones.

Broken
Fixed
Watch out. If you see {price} in your output, you forgot the f. Use 'single' outside and "double" inside, or the other way round.

Interview Studio

Five questions interviewers ask about string methods

Why does s.upper() not change s?
Strings are immutable, so every method returns a new string. Save it: s = s.upper().
What is the difference between split() and split(' ')?
split(' ') cuts at every single space, so double spaces give empty pieces. split() splits on any run of whitespace and drops empty pieces.
find() versus index()?
Both return the position. When the text is missing, find returns -1 and index raises ValueError.
How do you put a number with 2 decimals and a comma into text?
f'{value:,.2f}'. For example f'{125812.07:,.2f}' gives 125,812.07.
How do you join a list of words into one sentence?
' '.join(words). The separator calls join, and the list goes inside the brackets. Items must already be strings.

Key Takeaways

Six rules to remember

1 · Methods return new text

Assign the result: s = s.strip().

2 · Clean, then compare

strip().lower() before you compare or count.

3 · split and join

Cut with split(sep), glue with sep.join(list).

4 · split() vs split(' ')

No argument handles any run of spaces.

5 · f-strings

f'{x:,.2f}' for money. {x=} to debug.

6 · find vs index

find gives -1, index raises an error.
