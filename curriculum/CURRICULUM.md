# import TheShiraverse: Python for Data Analysts, curriculum v2 (2026-11-21, DRAFT: merged with Ali's Aug 2025 Trainer Edition Section 1 + 3)

Site: python.theshiraverse.com. Part of the TheShiraverse Data Science & AI path (SQL -> Python -> maths -> ML -> deep learning -> NLP/vision -> MLOps).
Runs in the browser (Pyodide). Dataset: RetailMart. Every topic links back to SQL ("how did I do this in SQL?").
Topic numbers are stable: topics 1 (built) and 2 (next) keep their places.

## Get started (do once)
1. Meet Python (what it is, Python vs SQL vs Excel)
2. Run Python in the browser (playground tour)
3. Set up Python on your laptop (Anaconda/Miniconda, venv, pip, Jupyter, VS Code)
4. Load RetailMart into pandas
5. Website walkthrough
